# Guides

Choose the path that matches what you are doing now.

## Build an application from end to end

Follow the [Guide](/tutorials/guide/) to grow one application from the framework shell into menus, custom windows, scrolling content, responsive layouts, dialogs, controls, and committed form data.

The chapters build on one another and point to runnable, tested PHP examples.

## Add one capability

Open the [Cookbook](/cookbook/) when the application already runs and you need a focused recipe:

- [Structure a larger application](/cookbook/structure-an-application)
- [Handle events and commands](/cookbook/events-and-commands)
- [Build menus and status lines](/cookbook/menus-and-status-lines)
- [Build dialogs and forms](/cookbook/dialogs-and-forms)
- [Use scrolling, lists, and editors](/cookbook/scrolling-lists-and-editors)
- [Render and capture applications](/cookbook/render-and-capture)
- [Add help and persistence](/cookbook/help-and-persistence)

Use the [component catalog](/reference/component-catalog) when you know the kind of control you need but not its class or primary methods.
